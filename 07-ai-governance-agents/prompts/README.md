# Prompt-Bibliothek

krisensicherOS folgt einem Empowerment-first-Ansatz.

Das Ziel ist nicht, Nutzer abhängig von Beratern oder Agenten zu machen. Das Ziel ist, interne ISB-/CISO- und Governance-Teams zu befähigen, ihr eigenes agentisches Arbeitsmodell zu verstehen, aufzubauen, zu prüfen und weiterzuentwickeln.

## Zweck

Die Prompt-Bibliothek hilft Nutzern dabei:

- Agenten sinnvoll zu briefen,
- eigene Compliance-Register aufzubauen,
- NIS2-/ISMS-/BCMS-Fragen strukturiert zu bearbeiten,
- Ergebnisse kritisch zu prüfen,
- Managemententscheidungen vorzubereiten,
- keine Verantwortung an Agenten auszulagern.

## Grundregel

Prompts in krisensicherOS sollen nicht magisch wirken. Sie sollen erklären, welche Inputs gebraucht werden, welche Outputs entstehen und wo menschliche Prüfung erforderlich ist.

## Prompt-Qualitätskriterien

Ein guter krisensicherOS-Prompt enthält:

1. Kontext
2. Rolle des Agenten
3. Ziel
4. Eingangsdaten
5. gewünschtes Output-Format
6. Grenzen
7. Review-/Freigabehinweis
8. nächsten Schritt

## Anti-Pattern

Nicht verwenden:

- „Mach mir ein fertiges ISMS.“
- „Bestätige, dass wir NIS2-compliant sind.“
- „Erstelle eine ISO-27001-konforme Dokumentation.“
- „Bewerte den Vertrag verbindlich.“

Besser:

- „Hilf mir, eine Gap-Analyse vorzubereiten.“
- „Leite Fragen für den menschlichen Review ab.“
- „Mappe diese eigene Zusammenfassung auf mögliche Evidenzbedarfe.“
- „Formuliere Entscheidungsoptionen für das Management.“
