# Getting Started

## Purpose

This folder guides you through the first krisensicherOS end-to-end passes. Use the paths only with an approved AI environment and marked human gates.

## What do you want to achieve?

Choose the goal first, not the folder.

| Goal | Entry point |
| --- | --- |
| Roughly classify NIS2 and capture the first gap | [`anwenderpfade.md`](anwenderpfade.md) → Path 1 or [`minimaler-nis2-start-in-5-artefakten.md`](minimaler-nis2-start-in-5-artefakten.md) |
| Start a small ISMS | [`anwenderpfade.md`](anwenderpfade.md) → Path 2 and [`../../09-implementation-roadmaps/examples/fiktiver-mittelstand/isms-90-minuten-durchstich.md`](../../09-implementation-roadmaps/examples/fiktiver-mittelstand/isms-90-minuten-durchstich.md) |
| Organize evidence and management review | [`anwenderpfade.md`](anwenderpfade.md) → Path 3 |
| Practice incident/notification readiness | [`anwenderpfade.md`](anwenderpfade.md) → Path 4 |
| Make AI systems visible for EU AI Act readiness | [`eu-ai-act-readiness-start.md`](eu-ai-act-readiness-start.md) or [`anwenderpfade.md`](anwenderpfade.md) → Path 5 |
| Bundle suitable templates | [`artefaktpakete.md`](artefaktpakete.md) |

## Recommended sequence

1. Choose a goal in [`anwenderpfade.md`](anwenderpfade.md).
2. Open only the suitable package from [`artefaktpakete.md`](artefaktpakete.md).
3. After 15 minutes, check: scope, owner, human gates, and first output in place?
4. Then optionally use the [`30-60-90-minuten-nutzungspfad.md`](30-60-90-minuten-nutzungspfad.md).

## Boundaries

Does not provide legal advice, data protection advice, compliance assurance, or certification assurance. Management decisions, risk acceptance, external communication, and legal/data protection assessment remain with accountable humans.
