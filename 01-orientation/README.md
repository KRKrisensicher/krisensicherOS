# 01 Orientation

This module is the entry point into krisensicherOS. It clarifies purpose, boundaries, AI usage approval, data classes, source logic, and the smallest useful start.

**Operating logic:** Used at the beginning of a governance initiative to define the target picture, scope, non-goals, responsibility boundaries, working mode, and human gates.

## Start here

1. Read the `5-artifact quick start` (`getting-started/minimaler-nis2-start-in-5-artefakten.md`) first if you need a small NIS2 walkthrough.
2. Choose exactly one entry point in the `user paths` (`getting-started/anwenderpfade.md`): NIS2, ISMS, evidence review, incident readiness, or EU AI Act readiness.
3. Check the `AI setup guide` (`setup/README.md`) and use only approved AI environments.
4. Use the `AI usage approval matrix` (`../07-ai-governance-agents/templates/ki-nutzungsfreigabe-matrix.md`) to define data class, tool approval, redaction, and human gates.
5. Review product boundaries in `What we deliberately do not build` (`product-positioning/was-wir-bewusst-nicht-bauen.md`).

## Human gates

Stop before productive use if AI approval, data class, tool approval, or responsibility is unclear. Legal assessment, data protection assessment, risk acceptance, management decisions, and external communication always remain with accountable humans.

## Typical outputs

- clarified scope,
- approved data class and AI environment,
- marked human gates,
- selected user path,
- first next work step in 03, 04, 05, 06, or 07.
