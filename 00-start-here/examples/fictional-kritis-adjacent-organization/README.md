# Fictional Example: KRITIS-adjacent Organization

## Fictionality

This example is entirely fictional. It contains no real operator, facility, customer, person, incident, network, or system data.

## Initial Situation

A fictional KRITIS-adjacent organization operates critical support processes and wants to connect security governance, BCMS readiness, incident readiness, and evidence work more closely.

## Goal

Structure resilience and governance work so that critical processes, dependencies, escalations, evidence packs, and management decisions fit together.

## Example Flow

1. Describe the critical process and supporting dependencies as a fictional scope.
2. Complete the BCMS Critical Process Canvas.
3. Prepare the Incident Escalation Card for initial assessment and escalation.
4. Plan a tabletop exercise with a fictional scenario.
5. Create an Evidence Pack Index for exercise and review evidence.
6. Prepare the board briefing with options, risks, and decisions.
7. Mark stop points for live crisis, external communication, and legal assessment.

## Example Output

### Critical Process

- Process: fictional command and coordination function for a critical service.
- Dependencies: operations team, communication channel, restart procedure, supplier contact.
- Out of scope: real facilities, real network plans, real customer data.

### Decisions

| Decision | Options | Evidence | Decision-maker |
| --- | --- | --- | --- |
| Use restart target as a working assumption | conservative / staged / clarify later | BCMS Canvas | Management |
| Conduct tabletop | 60 minutes / 120 minutes / postpone | Exercise plan | Crisis team lead |
| Evidence Pack Review cadence | monthly / quarterly | Evidence Index | Security Governance Owner |

### Lessons Learned from Fictional Exercise

| Observation | Improvement | Owner |
| --- | --- | --- |
| Escalation role was unclear | Add roles matrix | Governance Owner |
| Communication point was missing | Add to Incident Escalation Card | Incident Owner |
| Evidence was distributed | Maintain Evidence Pack Index | Evidence Reviewer |

## Boundaries

This example is not live crisis management, does not provide a security assurance, and does not provide confirmation of regulatory fulfillment. Real KRITIS, security, legal, and communication decisions remain with accountable humans.
