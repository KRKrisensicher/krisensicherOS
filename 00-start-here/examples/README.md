
# Beispiele

Die Beispiele zeigen, wie krisensicherOS-Artefakte zusammenspielen. Alle Beispiele sind vollständig fiktiv.

## Grundregel

Keine echten Organisations-, Kunden-, Personen-, Vertrags-, Incident-, System-, Netz- oder Kontaktdaten in Beispiele schreiben.

## Beispielsets

- [`fiktiver-mittelstand/`](fictional-midmarket/) — kleiner Governance-Start mit NIS2-/ISMS-Fokus; enthält einen konkreten [`NIS2-Minidurchstich`](fictional-midmarket/nis2-minidurchstich.md) und einen [`ISMS-90-Minuten-Durchstich`](fictional-midmarket/isms-90-minuten-durchstich.md).
- [`fiktive-kritis-nahe-organisation/`](fictional-kritis-adjacent-organization/) — BCMS-, Incident- und Evidence-Readiness für einen kritischen Prozess.
- [`fiktive-interne-isb-ciso-funktion/`](fictional-internal-security-function/) — Entlastung einer internen ISB-/CISO-Funktion durch Priorisierung, Evidenz und Management Review.

## Grenzen

Beispiele sind Demonstrationen. Sie bestätigen keine rechtliche Anwendbarkeit, keine regulatorische Erfüllung, keine Zertifizierungsfähigkeit und keine Sicherheit. Menschliche Prüfung, Risikoakzeptanz und Managemententscheidungen bleiben erforderlich.
