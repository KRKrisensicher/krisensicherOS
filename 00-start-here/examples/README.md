# Examples

The examples show how krisensicherOS artifacts work together. All examples are fully fictional.

## Basic rule

Do not write real organization, customer, person, contract, incident, system, network, or contact data into examples.

## Example sets

- `fiktiver-mittelstand/` (`fiktiver-mittelstand/`) — small governance start with NIS2/ISMS focus; includes a concrete `NIS2 mini walkthrough` (`fiktiver-mittelstand/nis2-minidurchstich.md`) and an `ISMS 90-minute walkthrough` (`fiktiver-mittelstand/isms-90-minuten-durchstich.md`).
- `fiktive-kritis-nahe-organisation/` (`fiktive-kritis-nahe-organisation/`) — BCMS, incident, and evidence readiness for a critical process.
- `fiktive-interne-isb-ciso-funktion/` (`fiktive-interne-isb-ciso-funktion/`) — support for an internal information security officer/CISO function through prioritization, evidence, and management review.

## Limits

Examples are demonstrations. They do not confirm legal applicability, regulatory fulfillment, certification capability, or security. Human review, risk acceptance, and management decisions remain required.
