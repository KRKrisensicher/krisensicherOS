# Implementation Guides

This area contains practical implementation aids for security governance, ISMS, NIS2 readiness, and crisis readiness.

The guides are not standard texts, do not provide legal advice, and do not provide certification assurance. They translate requirements, risks, and governance objectives into roles, routines, decisions, evidence, and reviews.

## Guides

- [`isms/`](isms/) — ISMS implementation guide: roles, routines, evidence, and reviews.

## Working Rule

Each guide must answer:

- Who uses it?
- When is it used?
- Which decision or routine does it support?
- What evidence is created?
- Which human approval remains required?
