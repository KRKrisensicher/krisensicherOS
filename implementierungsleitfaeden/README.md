# Implementierungsleitfäden

Dieser Bereich enthält praktische Umsetzungshilfen für Security Governance, ISMS, NIS2-Readiness und Krisenfähigkeit.

Die Leitfäden sind keine Normtexte, keine Rechtsberatung und keine Zertifizierungszusage. Sie übersetzen Anforderungen, Risiken und Governance-Ziele in Rollen, Routinen, Entscheidungen, Evidenz und Reviews.

## Leitfäden

- [`isms/`](isms/) — ISMS-Umsetzungsleitfaden: Rollen, Routinen, Evidenz und Reviews.

## Arbeitsregel

Jeder Leitfaden muss beantworten:

- Wer nutzt ihn?
- Wann wird er genutzt?
- Welche Entscheidung oder Routine unterstützt er?
- Welche Evidenz entsteht?
- Welche menschliche Freigabe bleibt erforderlich?
