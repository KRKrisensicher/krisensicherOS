# Playbooks

Wiederholbare Ablaufpläne für Governance-, NIS2-, ISMS-, Incident-, Krisen- und Review-Situationen.

Playbooks verbinden Situation, Ziel, Rollen, Ablauf, Entscheidungen, Eskalation, Outputs, Nachbereitung und Lessons Learned.

## Grenzen

- keine Rechtsberatung
- keine Datenschutzberatung
- keine Zertifizierungs- oder Konformitätszusage
- keine Live-Krisenleitung durch Agenten
- keine Managemententscheidung durch Agenten
- keine echten Kunden-, Personen- oder vertraulichen Organisationsdaten in öffentlichen Beispielen
