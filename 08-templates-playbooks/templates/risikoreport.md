# Risk Report

## Purpose

SoA optional: The report can present pure risk-control mappings or an organization-specific SoA extension. ISO 27001 content is not included.

This template condenses the risk analysis register, risk-control map / SoA extension, and action status into a report for a risk workshop, management review, or steering body.

For a presentable HTML version, see `risikoreport-html.html` (`risikoreport-html.html`).
