# Beispiele

Die Beispiele zeigen, wie krisensicherOS-Artefakte zusammenspielen. Alle Beispiele sind vollständig fiktiv.

## Grundregel

Keine echten Organisations-, Kunden-, Personen-, Vertrags-, Incident-, System-, Netz- oder Kontaktdaten in Beispiele schreiben.

## Beispielsets

- [`fiktiver-mittelstand/`](fiktiver-mittelstand/) — kleiner Governance-Start mit NIS2-/ISMS-Fokus; enthält einen konkreten [`NIS2-Minidurchstich`](fiktiver-mittelstand/nis2-minidurchstich.md) und einen [`ISMS-90-Minuten-Durchstich`](fiktiver-mittelstand/isms-90-minuten-durchstich.md).
- [`fiktive-kritis-nahe-organisation/`](fiktive-kritis-nahe-organisation/) — BCMS-, Incident- und Evidence-Readiness für einen kritischen Prozess.
- [`fiktive-interne-isb-ciso-funktion/`](fiktive-interne-isb-ciso-funktion/) — Entlastung einer internen ISB-/CISO-Funktion durch Priorisierung, Evidenz und Management Review.

## Grenzen

Beispiele sind Demonstrationen. Sie bestätigen keine rechtliche Anwendbarkeit, keine regulatorische Erfüllung, keine Zertifizierungsfähigkeit und keine Sicherheit. Menschliche Prüfung, Risikoakzeptanz und Managemententscheidungen bleiben erforderlich.
