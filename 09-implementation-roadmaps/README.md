# Implementation Roadmaps

This area contains compact implementation plans for getting started with krisensicherOS.

Roadmaps are not a promise of compliance, certification, or security level. They structure sequence, roles, artifacts, human gates, and review points so that organizations can plan the next reliable work step.

## Contents

- [`30-tage-plan-v0.1.md`](30-tage-plan-v0.1.md) — 30-day start plan for a first governance slice.

## Usage

1. Check AI approval, data class, and permitted environment.
2. Select a narrow scope.
3. Select suitable templates, playbooks, workflows, and agent roles from `07-ai-governance-agents/` and `08-templates-playbooks/`.
4. Mark management, legal, data protection, and risk acceptance points as human gates.
5. Review, adapt, and release results through responsible roles.
