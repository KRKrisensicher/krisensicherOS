# Implementation Roadmaps

Dieser Bereich enthält kompakte Umsetzungspläne für den Einstieg in krisensicherOS.

Roadmaps sind keine Zusage auf Compliance, Zertifizierung oder Sicherheitsniveau. Sie strukturieren Reihenfolge, Rollen, Artefakte, Human Gates und Reviewpunkte, damit Organisationen den nächsten belastbaren Arbeitsschritt planen können.

## Inhalt

- [`30-tage-plan-v0.1.md`](30-tage-plan-v0.1.md) — 30-Tage-Startplan für einen ersten Governance-Durchstich.

## Nutzung

1. KI-Freigabe, Datenklasse und erlaubte Umgebung prüfen.
2. Einen schmalen Scope wählen.
3. Passende Templates, Playbooks, Workflows und Agentenrollen aus den Modulen `07-ai-governance-agents/` und `08-templates-playbooks/` auswählen.
4. Management-, Legal-, Datenschutz- und Risikoakzeptanzpunkte als Human Gates markieren.
5. Ergebnisse prüfen, anpassen und durch verantwortliche Rollen freigeben lassen.
