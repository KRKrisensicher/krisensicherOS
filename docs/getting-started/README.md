# Getting Started

## Zweck

Dieser Ordner führt durch die ersten krisensicherOS-Durchstiche. Nutze die Pfade nur mit freigegebener KI-Umgebung und markierten Human Gates.

## Was willst du erreichen?

Wähle zuerst das Ziel, nicht den Ordner.

| Ziel | Einstieg |
| --- | --- |
| NIS2 grob einordnen und ersten Gap erfassen | [`anwenderpfade.md`](anwenderpfade.md) → Pfad 1 oder [`minimaler-nis2-start-in-5-artefakten.md`](minimaler-nis2-start-in-5-artefakten.md) |
| ein kleines ISMS starten | [`anwenderpfade.md`](anwenderpfade.md) → Pfad 2 und [`../../examples/fiktiver-mittelstand/isms-90-minuten-durchstich.md`](../../examples/fiktiver-mittelstand/isms-90-minuten-durchstich.md) |
| Nachweise und Management Review ordnen | [`anwenderpfade.md`](anwenderpfade.md) → Pfad 3 |
| Incident-/Meldefähigkeit üben | [`anwenderpfade.md`](anwenderpfade.md) → Pfad 4 |
| KI-Systeme für EU-AI-Act-Readiness sichtbar machen | [`eu-ai-act-readiness-start.md`](eu-ai-act-readiness-start.md) oder [`anwenderpfade.md`](anwenderpfade.md) → Pfad 5 |
| passende Vorlagen bündeln | [`artefaktpakete.md`](artefaktpakete.md) |

## Empfohlene Reihenfolge

1. Ziel in [`anwenderpfade.md`](anwenderpfade.md) wählen.
2. Nur das passende Paket aus [`artefaktpakete.md`](artefaktpakete.md) öffnen.
3. Nach 15 Minuten prüfen: Scope, Owner, Human Gates und erster Output vorhanden?
4. Danach optional den [`30-60-90-minuten-nutzungspfad.md`](30-60-90-minuten-nutzungspfad.md) nutzen.

## Grenzen

Keine Rechtsberatung, Datenschutzberatung, Konformitäts- oder Zertifizierungszusage. Managemententscheidungen, Risikoakzeptanz, externe Kommunikation und rechtliche/datenschutzrechtliche Bewertung bleiben bei verantwortlichen Menschen.
