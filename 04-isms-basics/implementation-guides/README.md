
# ISMS-Umsetzungsleitfaden: Rollen, Routinen, Evidenz und Reviews

## Zweck

Dieser Leitfaden hilft Organisationen, ein Informationssicherheitsmanagementsystem als betreibbare Arbeitsweise aufzubauen: mit klaren Rollen, wiederkehrenden Routinen, Managemententscheidungen, Evidenzflüssen und Reviews.

Der Leitfaden unterstützt die praktische Arbeit mit ISO/IEC 27001 als Referenzrahmen. Er enthält keine Normtexte, keine Kontrollformulierungen und keine Zertifizierungszusage.

## Nutzung

Starte nicht mit allen Modulen gleichzeitig. Beginne mit Scope, Rollen und Risikosteuerung. Ergänze danach Betriebsroutinen, Nachweise, Management Review und interne Prüfungen.

Für einen kompakten ersten Durchstich nutze:

- [`../../docs/getting-started/anwenderpfade.md`](../../00-start-here/docs/getting-started/anwenderpfade.md) — Pfad „ISMS starten“.
- [`../../docs/getting-started/artefaktpakete.md`](../../00-start-here/docs/getting-started/artefaktpakete.md) — Paket „ISMS-Minimalstart“.
- [`../../examples/fiktiver-mittelstand/isms-90-minuten-durchstich.md`](../../00-start-here/examples/fictional-midmarket/isms-90-minuten-durchstich.md) — fiktives 90-Minuten-Beispiel.

## Umsetzungslogik

| Normnaher Begriff | krisensicherOS-Umsetzungslogik |
| --- | --- |
| Anforderung | Routine / Entscheidungspunkt |
| Control | Schutzmaßnahme / Arbeitsweise |
| Auditkriterium | Prüffrage / Evidenzspur |
| Dokumentation | Nachweisfluss |
| Verantwortlichkeit | Rolle mit Entscheidungskompetenz |

## Referenzrahmen

Die Module verweisen auf ISO/IEC 27001 als Referenzrahmen und ergänzen, sofern relevant, öffentliche NIS2-/BSIG-Bezüge. Die Anhang-A-Routinen nutzen eigene krisensicherOS-Arbeitstitel und übernehmen keine ISO-27002-Formulierungen. Die konkrete Auslegung, Anwendbarkeit und externe Zertifizierungsfragen müssen durch fachlich verantwortliche Personen geprüft werden.
